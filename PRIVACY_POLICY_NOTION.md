## 2. Information We Collect

### Data We Collect

| Data Type | Purpose | Storage Location |
|-----------|---------|------------------|
| 3D Facial Scans | Skin analysis using TrueDepth camera | Device only (local) |
| Skin Analysis Results | Generate skin metrics and insights | Device only (local) |
| Photos / Images | Track skin progress over time | Device only (local) |
| Device Information | Crash reporting and stability diagnostics | Device only (local) |

### Data We Do NOT Collect

- Your name, email, or contact information
- Location data
- Device identifiers for tracking
- Any data from other apps
- Biometric data for authentication purposes

### Data Security

All facial data is protected by multiple safeguards:

| Safeguard | Description |
|-----------|-------------|
| On-device processing only | Facial data is processed entirely on your device |
| No cloud storage | No biometric data is stored on any server |
| No transmission | Facial data is never transmitted over the internet |
| User control | You may delete all data at any time |
| Explicit consent | Camera access is requested prior to scanning |

## 3. How Your Data is Stored

### On-Device Architecture

| Feature | Description |
|---------|-------------|
| Local processing | All scans and analysis occur on-device |
| No server upload | Facial data is never uploaded |
| Offline functionality | App works without internet access |
| No user account | No sign-up or login required |

### Technical Details

- Data stored in iOS Core Data (SQLite) with iOS default encryption
- Protected by Apple's built-in security and app sandbox
- Data may be included in iOS device backups (iCloud or local)
- Accessible only by the Ollvy app

## 12. TrueDepth Camera Usage

Ollvy uses Apple's TrueDepth camera system:

- **Purpose:** Capture 3D facial geometry for skin texture analysis
- **Processing:** All processing happens on-device using Apple's ARKit
- **Storage:** Processed mesh data stored locally; raw camera feed is not saved
- **NOT for authentication:** This is NOT used for Face ID or biometric identification

Camera access can be revoked anytime: iOS Settings > Ollvy > Camera
